Comment obtenir la clé d'accès (une seule fois)
  1. Connectez-vous à github.com avec le compte propriétaire du dépôt.
  2. Ouvrez github.com/settings/personal-access-tokens/new.
  3. Nom : « Calendrier du gîte ». Expiration : 1 an. Repository access : « Only select repositories », puis le dépôt Montifaut.
  4. Permissions : « Repository permissions », ligne Contents, choisir Read and write. Rien d'autre.
  5. Cliquez sur « Generate token », copiez la clé (elle commence par github_pat_) et collez-la ci-dessus.

Cette clé ne donne accès qu'aux fichiers de ce dépôt. Ne la partagez avec personne. En cas de doute, supprimez-la sur GitHub : elle cesse aussitôt de fonctionner.
